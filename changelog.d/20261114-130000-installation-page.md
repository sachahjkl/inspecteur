**The install is in the settings: an Installation page.** It says where the installed copy is, its version, whether this copy is the installed one, the menu entry and the PATH, with Install, Repair, Upgrade and Uninstall. The command line is `--install`, `--uninstall`, `--status` (what is installed, and whether Inspecteur runs) and `--setup`, the same as in the other programs; `inspecteur install`, `uninstall`, `status` and the Install… command (Ctrl+Shift+I) are gone. The palette finds the page ("install").
